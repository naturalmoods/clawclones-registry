# ClawClones Public Registry — archived

Nominations have moved. ClawClones is now open source, so they live alongside
the code and the tracked list:

**→ [github.com/naturalmoods/clawclones/issues](https://github.com/naturalmoods/clawclones/issues)**

- [Nominate a clone](https://github.com/naturalmoods/clawclones/issues/new?template=clone-nomination.yml) — or open a PR adding it to [`projects.json`](https://github.com/naturalmoods/clawclones/blob/HEAD/projects.json)
- [Report wrong or stale data](https://github.com/naturalmoods/clawclones/issues/new?template=data-correction.yml)

This repository existed because the main one was private: it kept the
nomination process open to everyone while the code was not. That reason is
gone. The nine nominations filed here stay for the record.
